Power BI Project 2: Insurance Data Analysis


📊 Project Overview

    This project involves analyzing insurance data to uncover trends in customer demographics, policy types, and claim behaviors. The dashboard supports insurance teams in       identifying risk patterns and customer distribution.


🛠 Tools & Technologies

    Power BI Desktop
    
    MSSQL Server (Data source)
    
    Power Query
    
    DAX for measures and KPIs

📌 Key Features

    Data imported and profiled from SQL Server
    
    Custom visuals including donut charts, ribbon charts, matrix tables
    
    Drill-through filters to explore customer details
    
    Row-Level Security (RLS) implementation
    
    Scheduled refresh and Power BI Service publishing
